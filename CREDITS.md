# Credits and source attribution

## Original work

reMindMaze’s code, Canvas artwork, synthesized sound, castle setting, characters, and dialogue are original contributions to this repository. They are distributed under the MIT license. The room drawings are rendered from code; no downloaded image assets or external fonts are required.

## Wikipedia-based content

The starter pack’s question wording and concise factual explanations were newly written with reference to the Wikipedia articles below. This question pack and its adapted explanations are distributed under **Creative Commons Attribution-ShareAlike 4.0**:

https://creativecommons.org/licenses/by-sa/4.0/

Attribution: **Wikipedia contributors**, the authors of the articles linked below. Each article's **View history** page identifies its contributors. Each question also links directly to its source. Adaptations consist of new multiple-choice question phrasing, distractors, shortened explanations, and editorial difficulty assignments. Review date: 2026-09-25.

Live extracts shown in the reader are fetched separately from Wikipedia, shortened by the API, displayed as plain text, and labeled with article, contributors/history, and license links. When an API revision ID is returned, a permanent revision link is displayed too. Live text can differ from the reviewed starter-pack facts.

## Historical inspiration

Encarta MindMaze was the childhood inspiration for this project. This is an independent tribute; it is not affiliated with Microsoft or the Wikimedia Foundation. Microsoft’s original art, dialogue, music, questions, and game code are not included.

References used to establish the broad gameplay loop:

- [Microsoft Knowledge Base Q192590, archived](https://jeffpar.github.io/kbarchive/kb/192/Q192590/) — confirms the 20,000-point ending when taking the stairs, including Encarta 98.
- [MobyGames: Microsoft Encarta included game](https://www.mobygames.com/game/51797/microsoft-encarta-included-game/) — describes 10×10 floors, unlocked-door backtracking, question difficulties, subject choice, hints, characters, and encyclopedia links.
- [Wikipedia: Encarta MindMaze](https://en.wikipedia.org/wiki/Encarta_MindMaze) — historical overview.
